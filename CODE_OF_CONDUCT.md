# 🌱 Code of Conduct

We want Compressor contributions to remain welcoming, practical, and respectful.

## Expected

- Be courteous and assume good faith.
- Critique code and ideas, not people.
- Give actionable technical feedback.
- Respect maintainers' time and other contributors' work.
- Disclose security issues responsibly.

## Unacceptable

Harassment, discrimination, threats, doxxing, personal attacks, and sharing private information without consent are not acceptable.

## Enforcement

Report conduct concerns privately to the repository maintainer through GitHub. Maintainers may remove content or restrict participation when needed to protect the community.
